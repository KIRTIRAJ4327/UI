# Delivery Platform UI (starter)

The complete clickable product: 19 screens, light and dark mode, sample data in the browser.

```bash
npm install
npm run dev      # opens on #v3-home
npm run build    # production build in dist/
```

- Switch person with **View as** at the bottom of the sidebar.
- **Prototype controls** in the sidebar: guided tour and "Reset demo data".
- Search with Ctrl/⌘+K.

Screens live in `src/v3/`. Design tokens are in `src/index.css`. Project rules for Copilot are in `.github/copilot-instructions.md`.
