Architecture decision · written by the delivery agent · quality check passed
ADR-0173

Enforce the Registered Amortization maximum on Product Selection

In one paragraph

Advisors will no longer be able to enter more than 310 in Registered Amortization on the Product Selection page. They will see a short message explaining the limit. The check reuses the validator the form already uses, so no new service is added1.

The gap you are accepting

The Pricing API is not changed. A system calling the API directly could still save a value above 310. Priya has suggested a follow-up request to close it.

What gets changed

  • Product Selection form: blocks values above 3102
  • Shared amortization validator: gains the maximum3
  • One new message for advisors, and 3 new unit tests
