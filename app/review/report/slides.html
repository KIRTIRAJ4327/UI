    What the platform does

    One governed flow, from business request to release

    An AI agent does the work at each stage. A named person approves each gate.

    Business request, in plain language→eight gated stages→Released change + evidence trail
    Named approver at every gate
    With backups and separation of duties.
    One evidence trail
    Documents in Azure Blob, approvals in Azure SQL.
    Developers stay in VS Code
    The Developer Agent runs on their machine.

    The wider market

    Toolkits cover the work. Platforms add governance.

    Spec-driven toolkitGoverned delivery platformThis platform (prototype)
    • Toolkits score well on requirements and code, and low on governance.
    • With add-ons, Spec Kit moves up.

    Our answer

    Both, not either: Spec Kit builds, the platform governs

    A specification prevents the wrong thing being built. An approval record proves a responsible person accepted it.

    Spec Kit, in the repository

    • Requirement, plan and tasks before code
    • Any coding agent
    • Developer-led changes

    The platform, above it

    • Business approvals in plain language
    • Separation of duties and one audit record
    • Release, freeze, hold and rollback
